## Running the Project

1. Extract the project ZIP file.
2. Open **`index.html`** in Chrome, Edge, or another modern browser.
3. Use the dashboard and section pages to open each individual experiment.
4. Each browser-side experiment is stored in its own HTML file.
5. Node.js experiments include their source files and companion pages; run the `.js` files from a terminal with Node.js installed.

Some API or media demonstrations may require an internet connection or the relevant local media/resource.
